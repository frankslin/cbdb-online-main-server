## 程式碼品質檢查表

### ✅ 正確範例（BiogMainRepository）
```php
DB::transaction(function () use ($data) {
    // 1. 鎖定並更新資料
    $oldData = DB::table('POSTED_TO_OFFICE_DATA')
        ->where($pk)
        ->lockForUpdate()
        ->first();
    
    DB::table('POSTED_TO_OFFICE_DATA')
        ->where($pk)
        ->update($data);
    
    // 2. 記錄操作
    $operation = $this->operationRepo->store(...);
    
    // 3. 寫入審計日誌
    $auditLog->write('POSTED_TO_OFFICE_DATA', 'UPDATE', ...);
});
```

### ❌ 錯誤範例（多數控制器）
```php
// 危險：三次獨立寫入，無事務保護
DB::table('ALTNAME_DATA')->insert($data);          // 寫入 1
$operation = $this->operationRepo->store(...);     // 寫入 2
(new AuditLogService())->write(...);               // 寫入 3 ⚠️ 若失敗，前兩步已提交
```
